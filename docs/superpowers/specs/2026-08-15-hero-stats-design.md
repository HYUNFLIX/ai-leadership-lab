# 히어로 교육실적 노출 (라이브 배지 + 스탯 바) — 설계

날짜: 2026-08-15 · 대상: index.html 히어로 섹션

## 목적

히어로에서 "지금 많이 찾는 강사"라는 인기 신호를 즉시 전달한다. 누적 건수 대신
**최근성 있는 숫자**(올해 강의 횟수)를 사회적 증거로 사용한다.

## 구성

### 1. 라이브 배지 (기존 배지 교체)

- `AI Leadership Innovation` → `● 2026년 올해만 85회 출강`
- 초록 라이브 도트가 은은히 펄스(글라스모피즘 톤 유지, 이모지 금지)
- HTML에 현재 시점 숫자를 정적으로 포함(API 실패 시에도 정상 노출), API 응답 시 갱신

### 2. 스탯 바 (버튼 아래 한 줄)

`올해 강의 85회 · 출강 기업·기관 60곳 · 교육 수료생 3,000+`

- About 섹션과 동일한 카운트업 애니메이션(ease-out, 1.2s)
- 앞의 두 항목은 `#projects`(강의 실적) 앵커 링크 — 별도 "실적 버튼"을 대체
- 데스크톱 좌측 정렬, ≤1024px 중앙 정렬, 좁은 화면 flex-wrap

### 3. 데이터 로직

- 기존 `LECTURES_API`(`/public/lectures`)를 페이지 로드 시 1회 fetch하는 공유
  promise(`fetchLectures()`)로 통일 — 기존 `#projects` 지연 로더도 같은 promise 사용
  (중복 호출 제거)
- 올해 건수 = `date`가 현재 연도로 시작하는 건수, 기업 수 = 고유 `client` 수
- **연초 보정**: 올해 건수 < 20이면 배지·스탯을 "최근 12개월 N회"로 자동 전환
- 수료생 3,000+은 정적 값(About 섹션과 동일 출처)

### 4. 접근성·성능

- `prefers-reduced-motion`: 카운트업·도트 펄스 생략, 최종 숫자 즉시 표시
- 스탯 바에 `aria-label="교육 실적 요약"`, API 실패 시 정적 숫자 유지(에러 UI 없음)

## 비채택 안

- 히어로 세 번째 "실적 버튼": 핵심 CTA(강의 문의) 분산 → 숫자 자체를 링크로 대체
- 최근 강의 티커(기업명 노출): 고객사 노출 리스크, 서비스 섹션과 중복
